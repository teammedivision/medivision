Pipeline

How It Works

MediVision runs a two-stage neural inference pipeline. There is no manual domain selection — the system routes your image to the correct specialist model and returns interpretable output you can show a clinician.

1Upload
2Auto-route
3Classify
4Explain & advise
1

Upload Image

Drop or browse a clinical image — JPG, PNG, or WEBP, up to 10 MB. Files are processed in memory and never written to disk.

2

Automatic Routing

A ResNet50 domain classifier identifies whether the image is skin, eye, or dental and routes it to the correct disease model — no manual selection.

3

Disease Classification

A domain-specific, fine-tuned ResNet50 returns ranked probabilities. Optional symptom text refines the ranking using weighted keyword matching.

4

Explain & Advise

Grad-CAM heat-maps highlight the regions that drove the prediction, paired with a triage tier, common symptoms and recommended precautions.

System architecture

A single image flows through one domain router, is dispatched to the matching specialist model, and returns an interpretable result — no manual domain selection.

About the Project

About MediVision

MediVision is an academic capstone project for UTS 42028 — Deep Learning and Convolutional Neural Networks, exploring how a single web interface can deliver multi-domain medical image screening using interpretable CNN models.

Project

CNN-Based Multi-Domain Medical Image Screening for Skin, Eye, and Dental Disease Detection. Four ResNet50 models combine into one automated pipeline: a domain router and three disease classifiers.

Architecture

Backend: Flask REST API with TensorFlow 2 / Keras 3. Models load once at startup; uploads stay in memory. Frontend: vanilla HTML, CSS, and JavaScript — no framework, no build step.

Interpretability

Every prediction ships with a Grad-CAM heat-map overlay, a top-k probability ranking, a severity triage tier, common symptoms, precautions, and a plain-language explanation.

Datasets

Trained on curated public datasets including ISIC dermatology collections, Mendeley eye-disease imagery, and Roboflow dental image sets, de-duplicated and stratified before training.
